# Aija Gofmane – Grāmatvedība un konsultācijas

Live: https://aijagofmanegramatvediba.lv

Static one-page website (Latvian). No build step — Vercel serves `index.html` directly.

- `index.html` – the whole site (HTML + CSS + JS)
- `logo.webp` – full logo (title section), `wordmark.webp` – footer logo, `logo-header.webp` – favicon
- `hero-bg.webp` – title section background, `aija.webp` – portrait
